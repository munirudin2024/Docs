## BAB II LANDASAN TEORI

### 2.1 Cyber Security

Cyber Security adalah praktik melindungi sistem komputer, jaringan, perangkat, dan data dari akses tidak sah, serangan, atau kerusakan. Cyber security mencakup berbagai aspek, antara lain:

1. **Network Security** - Melindungi jaringan komputer dari penyusup
2. **Application Security** - Menjaga perangkat lunak bebas dari ancaman
3. **Information Security** - Melindungi integritas dan privasi data
4. **Operational Security** - Proses pengambilan keputusan untuk menangani dan melindungi aset data

### 2.2 Password dan Keamanannya

Password adalah serangkaian karakter yang digunakan untuk autentikasi pengguna. Password yang kuat memiliki karakteristik: 

| Kriteria | Keterangan |
|----------|------------|
| Panjang | Minimal 8 karakter, idealnya 12+ karakter |
| Huruf Besar | Mengandung minimal 1 huruf kapital (A-Z) |
| Huruf Kecil | Mengandung minimal 1 huruf kecil (a-z) |
| Angka | Mengandung minimal 1 angka (0-9) |
| Karakter Spesial | Mengandung minimal 1 simbol (! @#$%^&*) |

**Ancaman terhadap Password:**
- **Brute Force Attack** - Mencoba semua kombinasi password
- **Dictionary Attack** - Menggunakan kata-kata umum
- **Phishing** - Menipu pengguna untuk memberikan password
- **Keylogger** - Merekam ketikan keyboard

### 2.3 Array dalam C#

**Array Satu Dimensi:**
Array satu dimensi adalah struktur data yang menyimpan elemen-elemen dengan tipe data sama dalam satu baris linear. 

```csharp
// Deklarasi array 1 dimensi
string[] passwords = new string[10];
int[] scores = {85, 90, 78, 92, 88};
```

**Array Multi Dimensi:**
Array multi dimensi menyimpan data dalam bentuk tabel (baris dan kolom).

```csharp
// Deklarasi array 2 dimensi
string[,] activityLog = new string[50, 3];
int[,] matrix = new int[3, 3];
```

### 2.4 Procedure dan Function

**Procedure (void method):**
Procedure adalah blok kode yang melakukan aksi tertentu tanpa mengembalikan nilai. 

```csharp
static void TampilkanMenu()
{
    Console.WriteLine("=== MENU ===");
    Console.WriteLine("1. Option 1");
}
```

**Function (return method):**
Function adalah blok kode yang melakukan aksi dan mengembalikan nilai.

```csharp
static int HitungSkor(string password)
{
    int skor = 0;
    // logika perhitungan
    return skor;
}
```

### 2.5 Algoritma Sorting

**Bubble Sort:**
Bubble Sort adalah algoritma pengurutan sederhana yang bekerja dengan membandingkan elemen berdekatan dan menukarnya jika urutannya salah.

```
Proses Bubble Sort:
[5, 3, 8, 1] → [3, 5, 8, 1] → [3, 5, 8, 1] → [3, 5, 1, 8]
[3, 5, 1, 8] → [3, 5, 1, 8] → [3, 1, 5, 8]
[3, 1, 5, 8] → [1, 3, 5, 8] ✓ Terurut! 
```

**Kompleksitas Waktu:**
- Best Case: O(n)
- Average Case: O(n²)
- Worst Case: O(n²)

#### B. Function Menghitung Skor Password

```csharp
static int HitungSkorPassword(string password)
{
    int score = 0;

    if (password.Length >= 8) score++;
    if (MengandungHurufBesar(password)) score++;
    if (MengandungHurufKecil(password)) score++;
    if (MengandungAngka(password)) score++;
    if (MengandungKarakterSpesial(password)) score++;

    return score;
}
```

**Penjelasan:**

- Mengembalikan nilai integer (skor 0-5)
- Setiap kriteria yang terpenuhi menambah 1 poin

#### C.  Algoritma Bubble Sort

```csharp
static void SortSaran(string[] arr)
{
    int n = arr.Length;
    for (int i = 0; i < n - 1; i++)
    {
        for (int j = 0; j < n - i - 1; j++)
        {
            if (! string.IsNullOrEmpty(arr[j]) && !string.IsNullOrEmpty(arr[j + 1]))
            {
                bool jTinggi = arr[j].Contains("TINGGI");
                bool j1Tinggi = arr[j + 1].Contains("TINGGI");

                if (! jTinggi && j1Tinggi)
                {
                    // Swap
                    string temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                }
            }
        }
    }
}
```

**Penjelasan:**
- Menggunakan nested loop untuk membandingkan elemen
- Menukar posisi jika elemen prioritas TINGGI berada setelah SEDANG
- Hasil:  saran dengan prioritas tinggi ditampilkan lebih dulu

#### D. Enkripsi Caesar Cipher

```csharp
static string EncryptPassword(string password)
{
    char[] encrypted = new char[password.Length];
    int shift = 3;

    for (int i = 0; i < password.Length; i++)
    {
        encrypted[i] = (char)(password[i] + shift);
    }

    return new string(encrypted);
}
```

**Penjelasan:**
- Caesar Cipher menggeser setiap karakter sebanyak 3 posisi
- Contoh: 'A' (ASCII 65) → 'D' (ASCII 68)
- Password "abc" menjadi "def"

## BAB IV PENUTUP

### 4.1 Kesimpulan

Berdasarkan hasil perancangan dan implementasi aplikasi Cyber Security: Password Manager & Analyzer, dapat disimpulkan bahwa:

1. **Array Satu Dimensi** berhasil diimplementasikan untuk menyimpan daftar password (`savedPasswords[]`), username (`savedUsernames[]`), nama layanan (`savedNamaAkun[]`), dan level kekuatan (`strengthLevels[]`). Array 1D efektif untuk menyimpan data linear yang sejenis dengan kapasitas 100 data.

2. **Array Multi Dimensi** berhasil diimplementasikan melalui `activityLog[,]` yang menyimpan log aktivitas dengan 3 kolom (waktu, aksi, status) dan kapasitas 100 log. Array 2D sangat berguna untuk menyimpan data tabular.

3. **Algoritma Sorting (Bubble Sort)** berhasil diterapkan untuk mengurutkan:
   - Saran perbaikan password berdasarkan prioritas
   - Daftar password berdasarkan nama layanan secara alfabetis

4. **Procedure dan Function** berhasil digunakan untuk membuat program yang modular:
   - Procedure: `TampilkanMenu()`, `CekKekuatanPassword()`, `SimpanPassword()`, `LihatSemuaPassword()`, `CariDanGunakanPassword()`, `HapusPassword()`, `LihatLogAktivitas()`, dll.
   - Function: `HitungSkorPassword()`, `EncryptPassword()`, `DecryptPassword()`, `MengandungHurufBesar()`, `MaskPassword()`, `FormatField()`, dll.

5. **Fitur Tambahan** yang berhasil diimplementasikan:
   - Auto-save ke file (passwords.dat dan activity_log.dat)
   - Tampilan dinamis menyesuaikan lebar layar konsol
   - Cari & gunakan password dengan pencarian
   - Hapus password dari penyimpanan
   - Password masking untuk keamanan tampilan

6. **Studi Kasus Cyber Security** memberikan konteks nyata tentang pentingnya:
   - Password yang kuat (minimal 8 karakter, kombinasi huruf, angka, simbol)
   - Enkripsi data sensitif
   - Pencatatan aktivitas (logging) untuk audit keamanan

### 4.2 Saran

Untuk pengembangan aplikasi lebih lanjut, disarankan:

1. **Peningkatan Enkripsi**: Mengganti Caesar Cipher dengan algoritma yang lebih kuat seperti AES-256 atau menggunakan library kriptografi standar

2. **Database**: Menggunakan database (SQL Server/SQLite) untuk penyimpanan yang lebih aman dan efisien

3. **GUI**: Mengembangkan antarmuka grafis menggunakan Windows Forms, WPF, atau MAUI untuk pengalaman pengguna yang lebih baik

4. **Fitur Keamanan Tambahan**:
   - Master password untuk mengakses aplikasi
   - Deteksi password yang sudah pernah bocor (breach detection)
   - Two-factor authentication (2FA)
   - Pengingat untuk mengganti password secara berkala

5. **Fitur Manajemen**:
   - Export/Import data password (CSV, JSON)
   - Kategori password (Personal, Work, Banking, dll)
   - Pencarian dan filter yang lebih canggih

6. **Multi-platform**: Mengembangkan versi mobile (Android/iOS) atau web-based untuk akses dari berbagai perangkat
